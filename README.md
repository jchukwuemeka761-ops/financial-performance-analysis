# financial-performance-analysis
E1X Academy project analyzing global retail financial performance using Excel, SQL, and Power BI.
## Overview
This project examines a global retail business’s financial performance and profitability. The analysis covers revenue, gross margin, product categories, store and regional performance, promotions, and operating expenses.
## My work
- Cleaned and prepared data in Excel
- Used Pivot Tables and summary analysis to examine performance
- Wrote SQL queries to explore the data
- Built Power BI visuals to communicate findings
- Developed recommendations based on the analysis

## Key areas examined
- Revenue and gross margin
- Product, store, and regional performance
- Promotions and discounts
- Operating expenses, including rent

## Project files
- `excel/` — workbook and analysis
- `sql/` — SQL scripts
- `powerbi/` — Power BI report, if shareable
- `report/` — presentation or written summary
- `images/` — dashboard screenshots

## Learning
This project helped me practice data cleaning, SQL analysis, dashboard reporting, and explaining business findings.
